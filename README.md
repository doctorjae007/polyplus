# ห้องเรียนแยกตัวประกอบ

เกมคณิตศาสตร์สำหรับสมบัติการแจกแจงและการแยกตัวประกอบ รองรับห้องเรียนแบบ 2–6 กลุ่ม การแข่งขันรายบุคคล และโหมดฝึกคนเดียว ครูสร้างรหัส 6 หลัก ส่วนนักเรียนตั้งชื่อและเลือกอิโมจิจากมือถือ

## การใช้งาน

1. ครูเลือก **แบ่งกลุ่ม** (2–6 กลุ่ม) หรือ **รายบุคคล** แล้วกดสร้างห้อง
2. นักเรียนเปิดลิงก์เดียวกันและใส่รหัสห้อง 6 หลัก
3. นักเรียนตั้งชื่อ เลือกอิโมจิ และเลือกกลุ่ม (หนึ่งกลุ่มมีสมาชิกหลายคนได้)
4. ครูเลือกกิจกรรมแล้วกด **เริ่มกิจกรรม**
5. หากต้องการฝึกเอง ให้เลือก **ฝึกเล่นคนเดียว** จากหน้าหลัก

โหมดรายบุคคลจัดอันดับผู้ชนะ 1–5 จากจำนวนข้อที่ตอบถูก โดยใช้เวลารวมของคำตอบที่ถูกเป็นตัวตัดสินเมื่อคะแนนเท่ากัน
