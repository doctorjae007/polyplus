# ห้องเรียนแยกตัวประกอบ

เกมคณิตศาสตร์สำหรับสมบัติการแจกแจงและการแยกตัวประกอบ รองรับทั้งห้องเรียนแบบ 2–6 กลุ่มและโหมดฝึกคนเดียว ครูสร้างรหัส 6 หลัก ส่วนนักเรียนตั้งชื่อ เลือกอิโมจิ และเข้ากลุ่มจากมือถือได้หลายคนต่อกลุ่ม

## การใช้งาน

1. ครูเลือกจำนวน 2–6 กลุ่ม แล้วกด **สร้างห้องใหม่**
2. นักเรียนเปิดลิงก์เดียวกันและใส่รหัสห้อง 6 หลัก
3. นักเรียนตั้งชื่อ เลือกอิโมจิ และเลือกกลุ่ม (หนึ่งกลุ่มมีสมาชิกหลายคนได้)
4. ครูเลือกกิจกรรมแล้วกด **เริ่มกิจกรรม**
5. หากต้องการฝึกเอง ให้เลือก **ฝึกเล่นคนเดียว** จากหน้าหลัก
